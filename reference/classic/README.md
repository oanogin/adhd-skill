# Classic-generation stage references

Stage docs for projects with `generation: classic` (or no generation field) in
`project/config.json` — the pre-flows chain (`stories → prototype` groundwork;
`milestone-brief → ux-refine → tracer → features` per milestone). New projects use
the flows chain; see [../brief.md](../brief.md), [../flows.md](../flows.md),
[../realize.md](../realize.md). The `prototype` stage doc stays shared at
[../prototype.md](../prototype.md) — for classic it is the groundwork stage, for
flows it is an on-demand command.

To finish an in-flight classic milestone, follow these docs unchanged. New work on
a classic project adopts flows incrementally via `adhd evolve`.
